- (decision) Paradigma: layered + single-activity + UDF (recomendacion oficial Android); capas UI/domain/data; ViewModel como state holder; corrutinas/Flow
- (decision) SessionController como unico propietario del estado de sesion (sealed class Inactiva/Lanzando/Aislada/Deteniendo); UI y componentes SO observan via StateFlow; nadie mas muta el estado
- (decision) TargetAppLauncher como interfaz (produccion: Intent explicito; test: fake); inyectado via DI manual (app pequena, sin Hilt)
- (decision) OverlayController: ventana TYPE_APPLICATION_OVERLAY via createWindowContext; flags NOT_FOCUSABLE + LAYOUT_IN_SCREEN + KEEP_SCREEN_ON + SECURE; detector 4-taps (region 15x15, ventana 500ms); overlay opaco touchable
- (decision) PresenceForegroundService: FGS specialUse con notificacion + accion Detener; host del watchdog; se inicia tras overlay visible (regla Android 15)
- (decision) Watchdog: detecta pantalla apagada (PowerManager), overlay ausente/permiso revocado (canDrawOverlays), app objetivo fuera de primer plano (UsageStatsManager si concedido), HIDE_OVERLAY_WINDOWS; termina sesion con notificacion
- (decision) DataStore Preferences para config (app objetivo, aviso aceptado, intervalo); sin base de datos; estado de sesion efimero (no persiste)
- (decision) Stack: Kotlin 2.4.x, Compose BOM 2026.06.x, minSdk 26, targetSdk 36, AGP 9.3.0, Gradle 9.5+, JDK 17; testing JUnit4+Robolectric+Compose UI+UI Automator; mock APK com.microsoft.teams
- (decision) Comunicacion: SessionController es el unico orquestador; componentes SO (OverlayController, FGS, Watchdog) son clientes que reportan eventos y reciben ordenes; sin dependencias entre componentes SO entre si
- (decision) Deferred: Hilt (DI manual suficiente), multi-app objetivo, reanudacion tras reinicio, modo pantalla apagada, distribucion Play, lista de apps instaladas
- (change) Spine v2: AD-7 contrato SessionCommand + handshake OverlayShown; AD-8 Notifier unico publicador + canales fijos; AD-9 event loop consumidor unico + terminacion idempotente; AD-10 SessionEvent/TerminationReason fijos; AD-11 ForegroundMonitor; AD-12 Clock inyectable; watchdog gated por estado Aislada; constantes en SessionConstants
